## R&D Experience

### Social Navigation — Inria

**R&D Internship | March – August 2026 | Lyon, France**

**ROS 2 Inference Pipeline for a Pretrained DRL Social Navigation Policy**

Worked on the software integration and simulation-based evaluation of a pretrained deep reinforcement learning policy for mobile robot social navigation.

**Main contributions:**

- Developed a ROS 2 pipeline for online inference using an existing pretrained DRL policy.
- Integrated observation processing, model loading, and navigation command generation.
- Integrated and tested the inference pipeline within a Gazebo simulation environment.
- Implemented simulation evaluation scenarios using metrics such as success rate, collisions, timeouts, and trajectory length.
- Prepared the software for transfer to a LIMO mobile robot, including adaptations of ROS 2 observation and command interfaces.

**Validation scope:** The system was integrated and evaluated in simulation. Transfer to the physical LIMO robot was prepared but not fully validated on real hardware.

## Selected Robotics Projects

### 1. French Robotics Cup 2025 — PAMIs

**Embedded Robotics | C++ / Arduino | ESP32-C3**

Team-based project involving embedded software development and integration of a mobile robot for the French Robotics Cup.

**Technical contributions:**

- Developed embedded firmware for an ESP32-C3 microcontroller.
- Integrated motor encoders, time-of-flight (ToF) distance sensors, motors, and a servomotor.
- Implemented encoder pulse counting to monitor robot movement.
- Developed a finite-state machine to coordinate movement and actuation sequences.
- Implemented obstacle detection and stopping behavior.
