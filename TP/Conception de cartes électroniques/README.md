[English](./README.md) | [Français](./README.fr.md)

## Project Overview

This project was completed as a two-person academic lab assignment during my mechatronics engineering studies.

The objective was to develop practical skills in **printed circuit board (PCB) design** using **KiCad**, an electronic design automation (EDA) software tool.

Following technical instructions and using a selection of components partially specified by the instructor, we worked through the main stages of digital PCB design: schematic capture, component placement, PCB routing, 3D visualization, and Gerber file generation.

The project was primarily educational and was not intended to develop a finished electronic product for a specific application.

## Learning Objectives

The main objectives of this lab project were to:

- Become familiar with KiCad and its PCB design tools.
- Create an electronic schematic based on technical requirements and instructions.
- Consult component datasheets to identify appropriate electrical connections.
- Understand the transition from an electronic schematic to a PCB layout.
- Perform component placement and PCB trace routing.
- Explore the generation of manufacturing files for printed circuit boards.
- Visualize the resulting PCB design in three dimensions.

## Project Work

### 1. Electronic Schematic Design

The electronic schematic was developed collaboratively using KiCad, following the instructions provided during the lab.

Although some components and design constraints were specified by the instructor, the work required identifying appropriate electrical connections and consulting component datasheets.

**I personally contributed to part of the schematic design.**

[View the electronic schematic (PDF)](./Carte%20Electronique_schematic.pdf)

### 2. PCB Layout and Routing

After completing the schematic, we worked on the PCB layout using KiCad's PCB Editor.

This stage involved arranging the components on the board and routing the copper traces required to establish the electrical connections defined in the schematic.

**My main contribution to the project was PCB trace routing.**

This experience helped me develop a better understanding of how schematic connections are translated into a physical board layout.

### 3. 3D PCB Visualization

The project also includes a 3D representation of the PCB generated using KiCad.

This visualization provides an overview of the board's appearance and component arrangement.

![3D visualization of the PCB design](./Carte%20Electronique.jpg)

### 4. Gerber File Generation

As part of the lab, we also explored exporting Gerber files from KiCad.

Gerber files describe the different layers of a PCB and are commonly used to communicate manufacturing data to PCB fabrication services.

This step was performed for educational purposes only. The manufacturing files were not submitted to a PCB manufacturer.

## Project Scope and Limitations

This project was an educational exercise focused on learning the digital PCB design process.

The board was designed using KiCad, but **it was not physically manufactured, assembled, or tested on hardware**.

Therefore, the electrical functionality of the PCB was not experimentally validated.

Nevertheless, the project provided hands-on experience with several stages of PCB development and helped strengthen my electronics knowledge as part of my broader mechatronics engineering background.
